# Tarot Card Assets

Use one `.webp` file per card, matching the keys in
`src/lib/tarot/cardCatalog.ts`. Store the files directly in `public/assets`.

Examples:

- `major-00-the-fool.webp`
- `major-02-the-high-priestess.webp`
- `major-11-justice.webp`
- `cups-ace.webp`
- `wands-king.webp`

Recommended export:

- Ratio: `2:3`
- Minimum: `900x1350`
- Format: `.webp`
- Keep text out of the image when possible; the UI renders card names.
