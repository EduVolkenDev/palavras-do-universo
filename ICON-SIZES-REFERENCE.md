# Icon Sizes Quick Reference

## Desktop Sizes

### Journey Map Icons
- **Size:** 8rem → 14rem (128px → 224px)
- **Location:** Step-by-step journey section
- **Visual:** Large circular icons with glossy assets

### Access Guide Icons  
- **Size:** 7.5rem → 11rem (120px → 176px)
- **Location:** Experience access paths section
- **Visual:** SVG lucide icons in circular containers

### Floating Symbols
- **Size:** 8.5rem → 11.5rem (136px → 184px)
- **Location:** Feature cloud/floating symbols section
- **Visual:** Mixed SVG and image icons

### Marketplace Flow Icons
- **Size:** 4.5rem (72px)
- **Location:** Product cards/marketplace
- **Visual:** Small circular badge icons

## Mobile Sizes (< 768px)

### Journey Map Icons

### Access Guide Icons
- **Size:** 6.5rem → 9rem via 16vw (104px → 144px)

### Floating Symbols

### Marketplace Flow Icons

## Icon Enhancement Features

✨ **All icons now have:**
- Multi-layer radial gradients (gold, teal, purple)
- Enhanced drop shadows for depth
- Ambient glow halos
- Hover scale effects (8-12% increase)
- Smooth cubic-bezier transitions
- Pulsing glow animations
- Breathing ambient light rings

## Color Palette

### Primary Glow
- **Golden:** rgba(244, 213, 141, 0.2-0.42)
- **Use:** Main icon glow, warmth

### Secondary Glow
- **Teal:** rgba(167, 215, 197, 0.12-0.28)
- **Use:** Mystical accent, depth

### Accent Glow
- **Purple:** rgba(214, 200, 255, 0.14-0.16)
- **Use:** Additional depth layer

### Shadows
- **Dark:** rgba(0, 0, 0, 0.24-0.42)
- **Use:** Depth and elevation

## Animation Timings

- **Glow Pulse:** 4-5 seconds
- **Ambient Glow:** 3.5 seconds  
- **Hover Transitions:** 380-460ms
- **Easing:** cubic-bezier(0.16, 1, 0.3, 1)
